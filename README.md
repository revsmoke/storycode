# Story to Code

Tell user stories; Claude infers the app they imply and keeps re-shaping it (wireframes, HTML5 + vanilla JS web components, UI and data model) as stories are added or refined.

See [docs/PRD.md](docs/PRD.md) for the product requirements draft, and [docs/use-cases.md](docs/use-cases.md) and [docs/user-stories.md](docs/user-stories.md) for use cases and testable user stories.
